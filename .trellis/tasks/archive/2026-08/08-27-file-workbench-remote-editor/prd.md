# 文件工作区与远程文件编辑

## Goal

把左侧文件树从“只能管理、远程文件不能预览”提升为接近 VS Code 的文件工作流：用户可从工具栏快速上传、粘贴和新建；单击本地或远程文本文件后，在主内容区以独立文件页签查看和编辑；代码具备语法高亮及基础缩进辅助；Markdown 默认显示渲染结果，并可切换源码编辑。

## Background

- 当前文件树已经实现本地/远程右键菜单、复制粘贴、上传下载、新建、删除和冲突策略，但常用操作尚未放到刷新按钮旁边。
- 当前本地文件单击后打开 `FileViewer` 弹窗；远程文件会提示“不支持远程预览”。
- 现有 `FileViewer` 已具备语法高亮、自动缩进、行号、缩进参考线、Ctrl/Cmd+F 搜索、LF/CRLF 保留、未保存提示和 Markdown 渲染，无需引入新的编辑器或 Markdown 依赖。
- 远程文件服务已有连接池、SFTP、根目录约束和安全替换基础能力，但缺少受限全文读取与内存文本原子写回接口。
- 远程文件管理 PR #54 于 2026-08-27 仍处于打开、未合并状态；本任务依赖该分支中的文件操作能力，但最终作为独立 PR 提交。
- 用户明确要求 `.trellis/` 不进入提交，并且 Rust 格式化、编译、Clippy 和测试只在 GitHub Actions 运行。

## Requirements

### R1 — 文件树工具栏快捷操作

- 在刷新按钮后依次增加：上传文件、上传文件夹、粘贴、新建文件、新建文件夹。
- 上传文件/文件夹只对连接有效的远程项目显示；本地项目不显示上传按钮。
- 粘贴和新建操作对本地项目及连接有效的远程项目可用。
- 断链远程项目不得误显示为可操作状态；忙碌时按钮禁用，粘贴还需满足现有剪贴板身份校验。
- 所有按钮复用现有右键菜单的操作入口、冲突处理、busy ownership 和 i18n 文案，不复制文件操作逻辑。

### R2 — 主内容区文件页签

- 单击文件树中的本地或远程文本文件，在终端所在主内容区打开独立文件页签，不再弹出文件查看器。
- 主内容区增加工作区页签层：保留一个“终端”页，并可同时打开多个文件页。
- 同一项目、同一后端身份、同一路径只保留一个页签；再次点击时激活已有页签。
- 文件页签按项目隔离；切换项目后恢复该项目最后激活的终端页或文件页。
- 文件页签第一版只保存在运行时，不写入终端布局数据库，不在应用重启后恢复。
- 关闭有未保存修改的页签必须确认；切换页签、打开其它文件或切换项目不得丢失草稿和撤销栈。
- 文件被删除、连接失效或项目被删除时，页签显示明确错误或被安全关闭，不得写入错误目标。

### R3 — 编辑器能力

- 复用现有 `gpui-component` code editor，保留语言识别、语法高亮、行号、缩进参考线、自动缩进、撤销/重做和 Ctrl/Cmd+F。
- Ctrl/Cmd+S 保存当前文件；Ctrl/Cmd+W 关闭当前文件页签并遵守未保存确认。
- 文件页激活时，终端专属快捷键不得误操作后台终端。
- 保留文件原始主导行尾（LF/CRLF）；未知扩展名按纯文本打开。
- 保留现有 1 MiB 查看/编辑上限；超限、非 UTF-8 或二进制文件显示不可编辑提示和下载/外部打开出口。

### R4 — Markdown 默认渲染

- `.md`、`.markdown`、`.mkd`、`.mdx` 默认进入渲染预览。
- 文件页提供“预览 / 源码”切换；从源码切回预览时渲染当前草稿，不要求先保存。
- 保留现有标题、列表、表格、代码块高亮、图片和排版宽度等 Markdown 渲染能力。
- 本地 Markdown 的相对图片继续可用；远程 Markdown 第一版保证文本、表格和代码块渲染，SSH 相对图片加载单独延后。

### R5 — 本地文件读写

- 继续使用 `mt_project::fs::read_file_content` / `write_file_content` 的项目根约束、类型校验、大小限制和原子写入。
- 本地文件继续使用文件系统 watcher：干净文档发生外部变化时自动刷新，脏文档显示冲突提示。

### R6 — 远程文件安全读写

- 增加远程受限全文读取：每次读取都重新确认 SSH 连接身份、规范化项目根、目标仍位于根内，并拒绝符号链接和特殊条目。
- 远程读取最多获取 `1 MiB + 1 byte`，据此区分正常文本、超限和二进制，避免无界内存读取。
- 增加内存文本安全写回：内容先写入同目录唯一临时文件，flush/close 后通过现有 backup-swap 机制替换目标；失败时清理临时文件并尽力回滚。
- 页签绑定项目 ID、连接 ID、连接指纹/代次和规范化路径；连接配置变化后旧页签不得继续保存。
- 保存前重新读取远端当前内容并与载入/上次保存基线比较。检测到外部变化时先阻止覆盖，向用户提供“重新加载”和“仍然覆盖”选择。
- 远程文件第一版不持续轮询；手动刷新、重新激活及保存前校验负责发现远端变化。

### R7 — 搜索与现有入口兼容

- 全局搜索点击结果也通过同一文件页签管理器打开文件，并保留命中行定位。
- 现有本地文件查看能力迁移后不应再出现重复弹窗；如保留薄弹窗适配器，不得与文件页签形成两个状态源。

### R8 — 交付与验证

- 新功能在独立分支实现。开发起点可暂基于 PR #54 head；#54 合并后再整理到最新 `main`，新 PR 不携带旧 PR 的重复提交。
- `.trellis/`、task、journal、研究记录和个人配置不得进入产品提交或 PR diff。
- 本地仅做静态检查、i18n 生成/幂等和 `git diff --check`；不运行 `cargo fmt`、Cargo 编译、Clippy 或 Rust 测试。
- GitHub Actions 负责格式、i18n、Cargo check、Clippy、测试和 whitespace 检查。

## Acceptance Criteria

- [ ] AC1：刷新按钮后出现上传文件、上传文件夹、粘贴、新建文件、新建文件夹快捷图标，顺序、tooltip、禁用状态和本地/远程可见性符合 R1。
- [ ] AC2：工具栏动作与对应右键菜单调用同一业务入口；上传、粘贴、新建的冲突和错误行为没有分叉。
- [ ] AC3：单击本地文本文件会在主内容区新增或激活文件页签，不再打开 modal。
- [ ] AC4：单击远程文本文件不再显示“不支持远程预览”，而是读取并打开文件页签。
- [ ] AC5：同时打开多个文件时，各自草稿、撤销栈、预览/源码状态和脏状态独立；重复打开同一文件不会重复建页。
- [ ] AC6：关闭脏文件页签会确认；取消关闭后内容完整保留；切换终端/项目不会丢草稿。
- [ ] AC7：代码文件具有语法高亮、行号、缩进参考线和基础自动缩进；未知扩展名可按纯文本编辑。
- [ ] AC8：Markdown 默认显示渲染结果，可切换源码；未保存草稿切回预览时立即反映最新内容。
- [ ] AC9：本地保存继续保留 LF/CRLF、项目根边界和原子写入；本地外部修改提示行为不退化。
- [ ] AC10：远程读取/保存拒绝越界、符号链接、特殊条目、失效连接和超过 1 MiB 的内容。
- [ ] AC11：远程保存使用同目录 staging + backup-swap；失败不会留下半写目标，错误对用户可见。
- [ ] AC12：远端内容在编辑期间被修改时，首次保存不会静默覆盖；用户可选择重新加载或明确强制覆盖。
- [ ] AC13：全局搜索打开文件页签并定位命中行；相同文件与文件树入口去重。
- [ ] AC14：打开/关闭文件页不改变终端 `SplitNode`、PTY 生命周期或已保存终端布局；应用重启不恢复文件页签。
- [ ] AC15：文件页激活时 Ctrl/Cmd+S、Ctrl/Cmd+W、Ctrl/Cmd+F 作用于文件页，终端专属动作不会误触后台 pane。
- [ ] AC16：PR diff 不包含 `.trellis/`；GitHub Actions 的格式、i18n、Cargo check、Clippy、测试和 whitespace 全部通过。

## Key Decisions

- 使用独立 `WorkbenchArea`/文档页签管理层包裹现有 `TerminalArea`，不把终端 `PaneState` 改造成终端/文件联合类型。
- 每个打开文件拥有独立编辑器实体；文件页签运行时保存，不进入终端布局持久化。
- 本地和远程都支持文本/代码/Markdown 查看与编辑；远程相对图片、LSP 等高级 IDE 能力不进入第一版。
- 远程保存采用乐观并发保护：保存前比较远端基线，冲突时必须由用户明确选择。
- 不新增编辑器、高亮或 Markdown 依赖，复用已锁定的 `gpui-component` 与 tree-sitter 语言包。

## Constraints

- 不破坏现有终端分屏、终端 tab、AI 会话状态、PTY 回收、移动端同步和布局持久化。
- 不通过本地临时文件中转远程编辑保存。
- 不把远程文件路径交给本地默认应用或本地文件 URI。
- 不在本地运行 Rust 工具链质量检查。

## Out of Scope

- LSP、补全、诊断、代码格式化、重构、多光标、Git diff gutter 等完整 IDE 能力。
- 文件页签跨重启恢复、草稿崩溃恢复和工作区会话持久化。
- 远程文件系统持续 watcher/polling。
- 远程 Markdown 相对图片与远程 HTML/CSS/JS 的完整浏览器级预览。
- 大于 1 MiB 的文本编辑和通用二进制编辑；本地既有图片预览保持不变。
