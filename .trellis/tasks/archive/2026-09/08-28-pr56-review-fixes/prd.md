# PR #56 审核意见整改

## Goal

处理 `dreamlonglll/mini-term#56` 的合并前审核意见，消除本次文件工作区改动引入的显示回归与静默失败，并收紧远程 Markdown 的资源加载边界，同时保持本地文件预览、编辑和既有搜索体验可用。

## Background

- PR：`feat: 增加本地与远程文件工作区`（#56）。
- 审核者确认当前安全基础、依赖边界、异步竞态与全工作区测试总体通过，但提出 2 条必须修复项和 6 条需要确认或调整项。
- 用户要求按审核意见处理。
- Rust 编译、Clippy 和测试只在 GitHub Actions 执行，不在本地运行。
- `.trellis` 仅用于本地任务管理，不得进入功能提交或 PR 差异。

## Requirements

1. Markdown/HTML 清洗必须只处理真实的 AST 活动节点，不得改写 fenced code、inline code 或普通示例文本中的 HTML 属性。
2. 不安全链接与图片降级成纯文本时，必须保留包含标点的原始可见标签，并正确转义可能重新形成 Markdown 语法的标点。
3. 远程 Markdown/HTML 中的 HTTP(S) 图片默认不得自动发起网络请求。纯图片段落显示可点击占位，用户明确操作后才在应用内加载；复杂容器中的内联图片安全降级为 alt 文本。本地 Markdown 保持自动预览。
4. 搜索弹窗打开文件页签后应保留 query 和结果，重新打开即可继续排查；恢复“单击内置预览、双击外部编辑器”的既有语义；远程项目触发全局搜索时给出明确提示。
5. 文件页下载因项目、根路径或连接身份不匹配而无法执行时，必须给用户可见反馈，不得静默返回。
6. Markdown 图片预览布局应使用中栏页签的实际可用宽度，避免左右面板展开后按 viewport 宽度计算导致溢出裁剪。
7. worktree 目录消失但存在未保存文档时，自动移除项目被阻止必须给出提示，不能留下无解释的幽灵项目行。
8. 关窗时 AI 会话列表最多显示 5 条并汇总剩余数量的行为保留，并在 PR 回复中说明这是有意对齐既有冲突弹窗的可读性策略。
9. 不可信 Markdown（远程文档与 AI 会话）中的 raw HTML 节点不得进入 HTML 渲染器；必须降级为不会形成活动 DOM 的可见源码/纯文本。远程 `.html` 不再默认富文本预览，按源码查看与编辑，彻底消除手写 HTML 扫描器与 html5ever 树构建器分歧造成的资源加载绕过。
10. 远程替换已成功、仅确定性恢复备份清理失败后，后续保存不得被陈旧备份永久阻断；仅当目标缺失或提交状态不明确时保留并拒绝覆盖恢复数据。
11. 已加载的远程文档刷新失败时必须保留当前编辑器、内容、草稿和焦点能力，通过非阻断警告展示错误；首次加载失败仍可显示错误页。
12. 搜索结果单击打开文件并延迟关闭覆盖层后，当前活动文档必须重新获得内容焦点，使用户无需再次点击即可输入和保存；回调必须校验项目与活动文档身份。
13. 不可信 Markdown 清洗必须运行到解析不动点：每轮清洗后重新按 GFM 解析并检查活动 HTML、链接和图片节点；限定轮数内不能收敛或解析失败时，必须把原文整体降级为可见的缩进代码块，不能把一次清洗后的文本直接交给渲染器。
14. 已确认不能作为安全边界的 `sanitize_untrusted_html_urls` / `sanitize_remote_html_urls` 入口不得继续暴露在生产命名空间；仅供回归测试的入口必须使用 `#[cfg(test)]`，生产仍可保留本地可信 HTML 预览所需的底层改写逻辑。
15. 远程刷新警告必须在后续远程保存成功时清除，因为保存成功已证明连接恢复；保存失败不得误清除该警告。

## Acceptance Criteria

- [ ] AI 会话 Markdown 的 HTML/JSX 示例代码保持原文；真实 raw HTML 节点中的不安全属性仍被清洗。
- [ ] `[main.rs](src/main.rs)`、`![截图(1).png](./a.png)` 等降级后仍显示原标签文字，不出现笼统的 `link`/`image` 替代。
- [ ] 打开远程 Markdown/HTML 不会自动请求其中的 HTTP(S) 图片；纯图片段落点击占位后可按现有资源加载路径显示，复杂容器中的图片不形成活动资源节点。
- [ ] 搜索结果单击、双击、关闭并重新打开搜索弹窗后的状态恢复，以及远程项目快捷键提示均符合需求。
- [ ] 下载身份不匹配、worktree 脏文档阻止清理时均出现本地化 toast。
- [ ] 文件页中 Markdown 图片不会超过实际内容区宽度。
- [ ] 新增或更新的中英文文案 key、占位符和生成字典保持一致。
- [ ] 相对 `origin/main` 不包含 `.trellis`、构建产物、安装包或与审核无关的文件。
- [ ] GitHub Actions 的格式检查、i18n、Cargo check、sidecar、Clippy、完整测试和 whitespace 检查全部通过。
- [ ] PR #56 使用简短中文功能描述，并在审核评论中逐项说明处理结果与第 8 项取舍。
- [ ] 审核方给出的 `select/title`、`select/plaintext`、`template/col/title` 三个载荷在远程 Markdown、会话 Markdown 和远程 HTML 入口均不能生成会自动请求网络的活动 HTML；fenced/inline code 仍保持原文。
- [ ] `target exists + deterministic backup exists` 被识别为已提交后的陈旧备份并在继续保存前清理；`target missing + backup exists` 仍拒绝自动覆盖恢复数据。
- [ ] 已加载远程编辑器在激活刷新失败后仍显示原内容/草稿，错误仅作为警告；首次加载失败仍显示错误分支。
- [ ] 搜索结果单击后覆盖层关闭，活动文件编辑器能直接接收键盘输入与保存快捷键。
- [ ] HTML block type 1–5 后紧跟缩进 Markdown 图片、链接或 raw HTML 的载荷，经过生产清洗并再次 GFM 解析后不含任何活动资源或链接节点。
- [ ] 正常不可信 Markdown 在有限轮次内达到不动点且保持当前可见输出；解析失败或不收敛时整篇按源码安全显示。
- [ ] 失效 HTML 清洗包装器不进入非测试构建；本地可信 HTML URL 改写仍可用。
- [ ] 已加载远程文档先出现刷新警告、再保存成功后警告消失；保存失败时警告保留。

## Out of Scope

- 审核者明确列为不阻塞的既有行为：force-save 在草稿恢复原样时无响应、远程页签每次激活重读、本地保存无冲突检测。
- 新增远程全文搜索能力。
- 为列表、引用等复杂 Markdown 容器构建可交互的内联图片占位组件；这些图片本次降级为安全 alt 文本。
- 改变 PR #56 已确定的文件工作区总体交互模型。
- 引入 html5ever/RcDom 作为新的直接依赖；本轮选择更小且 fail-closed 的“不渲染不可信 raw HTML”边界。
